# Homepage correction recovery brief

This brief is the authoritative acceptance checklist for the corrective pass on the existing local candidate. Implement directly in this worktree. Do not delegate, create another task, push, or deploy.

## 1. Spain banner

- It must not read as a still image.
- Add clearly perceptible but restrained movement to the Spain/Madrid artwork itself, not merely a tiny pin animation.
- Preserve the integrated hero treatment and support `prefers-reduced-motion`.

## 2. Hero at 1920 x 1080

- Increase the visual distinction between the headline and supporting copy.
- Add breathing room between headline, supporting copy, CTA, and modality controls.
- Keep the horizontal placement in the dark image-safe area unless fresh browser evidence shows it is too far left.
- Lower the action and modality group so the composition is not stacked too high.

## 3. Course groups into Nuestra filosofia

- Give the transition enough background contrast to read as a deliberate new chapter.
- Remove the excessive empty space near the end of `Nuestra respuesta`.
- Replace the oversimplified light-blue icons with stronger icons from a previous approved version or production.
- Keep the icons inside the established navy, royal-blue, gold, and white palette.

## 4. Gallery

- Balance the left and right image columns so their compositions finish at the same visual height.
- Remove the pause/play control.
- Preserve smooth gallery movement without making the interface distracting.

## 5. Sedes

- Remove the black location rows and cards; return the section to the site's navy, royal-blue, gold, and white system.
- Make the map, location list, route, pins, and selected states feel like one visual system.
- A selected pin must not turn black.
- Judge the entire composition, not merely the pin color.

## 6. Empieza aqui and mobile pass

- Remove the oversized chapter or minimum-height behavior making `Empieza aqui` feel huge.
- Let `Empieza aqui` and FAQ size naturally to their content.
- Review every named section on representative mobile widths for spacing, hierarchy, overflow, image balance, control sizing, and tap targets.
- Verify the same fixes at 1920 x 1080 and on mobile before calling the work complete.

## Completion gate

Every correction requires desktop and mobile browser evidence. Run the repository validation and release-surface checks. Stop for owner review without committing, pushing, or deploying.
